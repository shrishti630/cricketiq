# 🏏 CricketIQ — IPL Intelligence Hub (Frontend)

A modern, high-performance **IPL Analytics and Agentic Cricket Intelligence Platform** built with **React 18 + Vite + TypeScript + Tailwind CSS**, designed strictly after the **Premier Zone** sports portal aesthetic.

---

## 🌟 Features

- **Premier Zone Visual Aesthetic**: Deep midnight sports theme (`#070A11`), dark glassmorphic cards, glowing amber/cyan highlights, and official IPL franchise badges.
- **Match Center & Live Tickers**: Live scoreboard for CSK vs MI, real-time in-game win probability meter, and high-voltage upcoming fixtures.
- **10 IPL Club Hubs**: Visual franchise grid showing titles, captains, coaches, home stadiums, and interactive squad roster modals.
- **Player Scout & Comparator**: Side-by-side head-to-head metric comparator evaluating Strike Rate, Average, Boundaries, Wickets, and Economy deltas.
- **Standings & Playoff Simulator**: Official IPL points table with form pills (W/L) and mathematical playoff qualification odds.
- **Interactive Fantasy XI Studio**: Cricket pitch layout with 11 role slots, 100.0 credit budget meter, C/VC multipliers, and an **"AI Auto-Optimize Squad"** solver.
- **AI Intelligence Hub & Slide-Out Drawer**: Grounded multi-agent reasoning with tool execution traces, evidence verification, and zero hallucinated numbers.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/shrishti630/cricketiq.git
cd cricketiq

# Install dependencies
npm install

# Start Vite development server
npm run dev
```

Visit `http://localhost:5173` to explore the app!

---

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite + TypeScript)
- **Styling**: Tailwind CSS + Custom Sports Glassmorphism
- **Icons**: Lucide React
- **Data & APIs**: REST endpoints with built-in realistic fallback datasets
